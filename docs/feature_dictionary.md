# Flight feature contracts

## Default raw-input pipeline

Categorical inputs: `AIRLINE`, `ORIGIN_AIRPORT`, `DESTINATION_AIRPORT`.
Numeric inputs: `MONTH`, `DAY`, `DAY_OF_WEEK`, `SCHEDULED_TIME`, `DISTANCE`.
`SCHEDULED_DEPARTURE` derives `scheduled_hour`; HHMM 2400 maps to hour zero.
`CANCELLED` and `DIVERTED` filter eligibility. `ARRIVAL_DELAY` is the regression
label and produces classification label `severe_delay = ARRIVAL_DELAY > 30`.
Labels and post-outcome delay causes are excluded from feature assembly.

The default pipeline clips DISTANCE/SCHEDULED_TIME using fitted training-fold
IQR bounds, imputes numeric values, encodes categoricals, scales sparse vectors
without centering and applies PCA. Serving uses the same fitted stages.

## Optional batch history adapter

`feature_integration.FlightFeatureContract` describes the batch feature set.
`scripts/build_modeling_dataset.py` reads typed raw flights and airports,
materializes features and writes to a new Parquet directory.

| Group | Derived features |
|---|---|
| Distance | Vectorized Arrow Haversine; raw DISTANCE miles converted to km as fallback; coordinate-availability flag |
| Airport mapping | Direct IATA matching, ranked DOT description matching and fixed manual overrides |
| Airline | Flight/late counts, total delay, distinct late aircraft, ratios; 1/3/7-day windows |
| Airport | Same-day scheduled departure/arrival counts; late count and average delay over 3/6/12 hours |
| Aircraft | Same-day schedule count, historical total delay and delay/km, previous flight delay |
| Flight | Departure delay/km, relative airline delay, scheduled local-clock duration and duration/km |
| Calendar | ISO weekday weekend flag and time-of-day category |
| Optional preprocessing | Fitted IQR clipping/flags; smoothed TargetEncoder with global-mean fallback |

Historical windows use epoch seconds and exclude the current timestamp.
Flight schedule keys include YEAR. The previous-flight lag is experimental:
flights with equal timestamps require deterministic ordering before production
use. All outcome-based history also requires checking when the actual outcome
became available, not only scheduled departure ordering.

Departure-delay features apply only after gate departure. Clock differences
between scheduled arrival and departure are not elapsed durations across time
zones. `airplane_prev_flight_delay_vs_current_schedule` mixes delay duration
and clock time and is excluded from the adapter's model feature list.

TargetEncoder is an Estimator/Model pair: fit only on training folds, persist
maps as Spark Params and use the fitted global mean for unseen categories.
It does not implement nested out-of-fold encoding within a training fold.
Batch history is not required or generated by the default streaming pipeline.

## Legacy model-ready contract

`feature_contract.py` preserves the ordered 23-feature vector required by
legacy recovered models. These feature vectors and historical benchmark
numbers must not be mixed with raw-input PipelineModels.
