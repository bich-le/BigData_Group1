# Data Dictionary

This dictionary describes **typed raw schema** generated by `scripts/prepare_data.py`.

Current inference contract: the model predicts **before the flight actually departs**.

> `Candidate feature` is a preliminary assessment only. The final feature set is determined by the Feature/Pipeline module.

## Flights

| Column | Type | Meaning | Role / status | Pre-departure? | Notes |
|---|---|---|---|---|---|
| `YEAR` | integer | Year of the flight | Candidate feature | Yes | The current dataset contains only the year 2015 |
| `MONTH` | integer | Month of the flight | Candidate feature / partition key | Yes | Domain 1–12; the flights Parquet dataset is partitioned by this column |
| `DAY` | integer | Day of the month | Candidate feature | Yes | Domain 1–31 |
| `DAY_OF_WEEK` | integer | Day of the week | Candidate feature | Yes | Domain 1–7 |
| `AIRLINE` | string | IATA code of the airline operating the flight | Candidate feature | Yes | Join `airlines.IATA_CODE`; coverage 100% |
| `FLIGHT_NUMBER` | string | Flight number assigned by the operating airline | Candidate feature | Yes | Identifier, relatively high cardinality |
| `TAIL_NUMBER` | string | Registration number of the specific aircraft operating the flight | **Requires review** | Need verification | High cardinality; verify availability before departure |
| `ORIGIN_AIRPORT` | string | Departure airport code | Candidate feature | Yes | Includes three-character IATA and five-digit numeric DOT codes |
| `DESTINATION_AIRPORT` | string | Destination airport code | Candidate feature | Yes | Includes three-character IATA and five-digit numeric DOT codes |
| `SCHEDULED_DEPARTURE` | string | Scheduled departure time in HHMM format | Candidate feature | Yes | `2400` is considered a valid convention |
| `DEPARTURE_TIME` | string | Actual departure time in HHMM format | Leakage | No | Known only after the flight begins its departure |
| `DEPARTURE_DELAY` | integer | Difference in minutes between actual and scheduled departure times | Leakage | No | Positive value = delayed; negative value = departed early |
| `TAXI_OUT` | integer | Minutes from gate departure to takeoff | Leakage | No | Post-departure |
| `WHEELS_OFF` | string | Time the aircraft leaves the ground, in HHMM format | Leakage | No | Actual time |
| `SCHEDULED_TIME` | integer | Total scheduled flight duration in minutes | Candidate feature | Yes | Not the actual elapsed time |
| `ELAPSED_TIME` | integer | Actual total time from departure gate to arrival gate | Leakage | No | Known only after the journey |
| `AIR_TIME` | integer | Actual time the aircraft spends in the air, in minutes | Leakage | No | Known only after the flight |
| `DISTANCE` | integer | Route distance between the origin and destination airports | Candidate feature | Yes | Raw route distance; not yet a Haversine feature |
| `WHEELS_ON` | string | Time the aircraft touches down, in HHMM format | Leakage | No | Actual time during the arrival stage |
| `TAXI_IN` | integer | Minutes from touchdown to arrival at the gate | Leakage | No | Post-arrival |
| `SCHEDULED_ARRIVAL` | string | Scheduled arrival time in HHMM format | Candidate feature | Yes | Known before departure |
| `ARRIVAL_TIME` | string | Actual arrival time in HHMM format | Leakage | No | Post-outcome |
| `ARRIVAL_DELAY` | integer | Difference in minutes between actual and scheduled arrival times | **Target** | No | Regression target; the expected classification label is `> 30`; negative means early arrival |
| `DIVERTED` | integer | Flag indicating whether the flight was diverted | Eligibility only | No | Domain 0/1; not used as a feature |
| `CANCELLED` | integer | Flag indicating whether the flight was cancelled | Eligibility only | No | Domain 0/1; not used as a feature |
| `CANCELLATION_REASON` | string | Flight cancellation reason code | Leakage | No | Available only after the cancellation decision |
| `AIR_SYSTEM_DELAY` | integer | Minutes of delay attributed to the air system | Post-outcome leakage | No | Missingness has business meaning; do not automatically fill with 0 |
| `SECURITY_DELAY` | integer | Minutes of delay due to security reasons | Post-outcome leakage | No | Missingness has business meaning; do not automatically fill with 0 |
| `AIRLINE_DELAY` | integer | Minutes of delay due to the airline | Post-outcome leakage | No | Missingness has business meaning; do not automatically fill with 0 |
| `LATE_AIRCRAFT_DELAY` | integer | Minutes of delay because the aircraft arrived late from its previous leg | Post-outcome leakage | No | Missingness has business meaning; do not automatically fill with 0 |
| `WEATHER_DELAY` | integer | Minutes of delay due to weather | Post-outcome leakage | No | Missingness has business meaning; do not automatically fill with 0 |

### Target eligibility

A row is eligible for both regression and classification:

```text
ARRIVAL_DELAY IS NOT NULL
AND CANCELLED = 0
AND DIVERTED = 0
```

Expected classification label:

```text
label = 1 if ARRIVAL_DELAY > 30
label = 0 otherwise
```

Typed raw does **not yet** contain a persisted label column.

## Known data notes

- `ARRIVAL_DELAY` null: 105,071 rows.
- The 105,071 rows with a null target comprise 89,884 cancelled + 15,187 diverted flights.
- Delay-cause columns are missing in about 81.725% of rows and have values only when `ARRIVAL_DELAY >= 15`.
- Direct airport IATA lookup coverage is about 91.645%.
- In October, 486,165 rows use five-digit numeric/DOT airport codes for both origin and destination.
- `ARRIVAL_DELAY` can validly be negative: the flight arrived early.
